# Changelog

All notable changes to Douxir are documented in this file.

## 1.0.0

Initial release.

- Documentation hub with nested documents, categories, a table of contents and pretty URLs
- Front-end layout with sidebar, live search, breadcrumbs, reading time, last updated date, previous/next links, related documents, print, helpful feedback and a mobile menu
- Drag-and-drop admin dashboard for creating, quick-editing and ordering documents and categories
- Settings screen for the docs slug, layout, search, permalinks, colors, typography, card style and custom CSS, with a live appearance preview
- Shortcodes and Gutenberg blocks for document lists, live search and categories
- JSON import and export of the knowledge base
